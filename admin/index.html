One-time setup

To save changes this page needs permission to write to your GitHub repository. You create a token once and paste it below. It is stored only in this browser and never sent anywhere except GitHub.

Open GitHub token settings, then: Repository access → Only select repositories → konnexplay-website. Under Permissions → Repository permissions → set Contents to Read and write. Generate it and copy the token.
